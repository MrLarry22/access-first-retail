# AccessFirst — Inclusive Retail Experience Framework

> Demonstrating how accessible design transforms the retail experience for every customer — not just some.

🔗 **[Live Demo →](https://mrlarry22.github.io/access-first-retail/)**

## About This Project

AccessFirst is an interactive web prototype that explores how universal design principles can revolutionise fashion retail. It features an interactive accessibility scorecard, a smart fitting room concept, and a visual guide to the "curb-cut effect" — the principle that solutions designed for people with disabilities consistently improve the experience for ALL users.

Built from lived experience: as someone who lives with contractures (a physical disability affecting joint mobility), I've experienced firsthand how design barriers exclude — and how thoughtful design includes.

## Features

- 🎯 **Interactive Accessibility Scorecard** — Rate any store across 5 dimensions and get actionable recommendations
- 🚪 **Curb-Cut Effect Gallery** — Visual examples of how accessibility innovations benefit everyone
- 💡 **Smart Fitting Room Concept** — Interactive prototype of a technology-enhanced, accessible fitting room
- 📐 **7 Universal Design Principles** — Each principle applied to real retail scenarios
- 📊 **Global Impact Statistics** — Data on disability demographics and business impact
- 🌙 **Dark Mode & High Contrast** — Toggle between themes for visual comfort
- ♿ **Fully Accessible** — WCAG 2.1 AA compliant: skip navigation, keyboard navigation, ARIA labels, focus indicators, `prefers-reduced-motion` support
- 📱 **Responsive** — Mobile-first design for all screen sizes

## Why This Project Matters

**1.3 billion people** worldwide live with some form of disability — that's 16% of the global population with **\$8 trillion** in annual spending power. Yet most retail experiences — physical and digital — are designed without accessibility in mind.

This project demonstrates that:
- Accessible design is **good business**, not just good ethics
- The "curb-cut effect" means improvements for the margins benefit the mainstream
- Technology can remove barriers with minimal investment and maximum impact
- Understanding diverse human needs leads to better products for everyone

## Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Grid, Flexbox, reduced-motion support
- **Vanilla JavaScript** — No external dependencies
- **Google Fonts** — Plus Jakarta Sans

## Accessibility Features

- Skip navigation link
- Proper heading hierarchy (h1 → h2 → h3)
- ARIA labels on all interactive elements
- `role="status"` and `aria-live="polite"` on dynamic content
- High contrast mode toggle
- Keyboard-navigable sliders and controls
- `prefers-reduced-motion` media query support
- Focus-visible indicators on all interactive elements
